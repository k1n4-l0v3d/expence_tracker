**Дата:** 2026-05-13  
**Подход:** Вариант A — polling каждые 4 сек, PostgreSQL хранение

---

## 1. База данных

### `shared_account_messages`

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER PK | |
| `shared_account_id` | FK → shared_accounts.id ON DELETE CASCADE | |
| `user_id` | FK → users.id | Автор |
| `text` | VARCHAR(1000) | Текст сообщения |
| `created_at` | DATETIME NOT NULL DEFAULT NOW | |

**Ограничение на 50 сообщений:** при добавлении нового сообщения, если `COUNT(*) > 50`, удаляются самые старые сверх лимита.

### `shared_account_reactions`

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER PK | |
| `message_id` | FK → shared_account_messages.id ON DELETE CASCADE | |
| `user_id` | FK → users.id | |
| `emoji` | VARCHAR(5) | `'❤️'` или `'👍'` |

Уникальный индекс: `(message_id, user_id, emoji)` — один пользователь не ставит одну реакцию дважды. Повторный клик снимает реакцию (toggle).

## 2. API-маршруты

| Маршрут | Метод | Описание |
|---|---|---|
| `GET /api/shared/<id>/messages` | GET | Последние 50 сообщений с реакциями |
| `POST /api/shared/<id>/messages` | POST | Отправить сообщение |
| `DELETE /api/shared/<id>/messages/<msg_id>` | DELETE | Удалить своё сообщение |
| `POST /api/shared/<id>/messages/<msg_id>/react` | POST | Поставить / снять реакцию |

### Защита

Все маршруты: `@login_required` + проверка членства в shared_account.  
Удаление: только если `message.user_id == current_user.id`.

### Формат ответа GET /messages

```json
[
  {
    "id": 42,
    "text": "Купи молоко",
    "created_at": "13.05 14:32",
    "is_mine": true,
    "author": {"username": "Иван", "avatar": "😎"},
    "reactions": {"❤️": 1, "👍": 0},
    "my_reactions": ["❤️"]
  }
]
```

### POST /messages — тело запроса

`application/x-www-form-urlencoded`: `text=<строка до 1000 символов>`

Возвращает: `{"ok": true}` или `{"error": "..."}`.

### POST /react — тело запроса

`emoji=❤️` или `emoji=👍`. Toggle: если реакция уже есть — удаляет, иначе добавляет.  
Возвращает: `{"ok": true, "action": "added"|"removed"}`.

## 3. UI — страница управления `/shared/<id>`

### Расположение

Третья секция на странице, ниже участников и формы приглашения. Ширина `col-12`.

### Структура блока

```
┌─ Чат ─────────────────────────────────────────────────────────┐
│  (scrollable area, height: 350px)                             │
│                                                               │
│  😎 Иван  13.05 14:32                                         │
│  ┌──────────────────────────────┐                             │
│  │ Купи молоко и хлеб           │  ❤️ 1  👍 0  🗑             │
│  └──────────────────────────────┘                             │
│                                                               │
│                           15.05 09:10  Маша 🐱               │
│                 ┌──────────────────────────────┐              │
│                 │ Уже купила!                  │  ❤️ 2  👍 1 │
│                 └──────────────────────────────┘              │
│                                                               │
├───────────────────────────────────────────────────────────────┤
│  [  Написать сообщение...              ]  [ Отправить ]       │
└───────────────────────────────────────────────────────────────┘
```

### Пузырьки

- **Своё сообщение** — правый пузырёк, фон коралловый (`var(--clr-primary-from)`), белый текст. Иконка 🗑 рядом для удаления.
- **Чужое сообщение** — левый пузырёк, фон нейтральный (`bg-body-secondary`). Аватар + имя над пузырьком.

### Реакции

Под каждым сообщением кнопки `❤️ N` и `👍 N`. Активная реакция выделена фоном. Клик — POST /react, затем обновление счётчика.

### Автообновление

`setInterval` каждые 4000 мс вызывает GET /messages. Если `id` последнего сообщения изменился — обновляет DOM и скроллит вниз. При открытой вкладке — запросы идут, при скрытой (`document.hidden`) — пропускаются для экономии.

### Отправка

- Enter (без Shift) или кнопка "Отправить"
- Пустое сообщение игнорируется
- После отправки: очистить поле + сразу дозагрузить сообщения
